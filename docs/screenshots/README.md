## What to capture

1. **server-list.png** — Guild rail: Friends / Direct Messages, then the AI bell under it. Native tooltip “AI notifications” is a plus.
2. **draft-reply.png** — A message with the hover reply-arrow, or the right-click menu showing **Draft a reply**, plus the AI window with a draft and **Insert into chat**.
3. **summarize.png** — Channel, thread, or DM right-click → **Summarize with AI** (Last hour / Today / This week), or the finished summary in the AI window.
4. **notifications.png** — AI notifications modal: briefing prose, jump links, **Summarize with AI** / **Clear all**.

Drop the four PNGs into this folder. The main README already has headings for them; image embeds go in once the files exist.
